# Automated tests

This namespace is reserved for **future host-side automated software tests**.

The standalone Wokwi/physical-hardware sketches that previously lived here were
reclassified in Wave 6 and now live under
[`diagnostics/`](../diagnostics/).

Do not place manual hardware diagnostics in this directory. Future automated
tests should be runnable non-interactively from the repository tooling/CI and
must not require a person to observe LEDs, displays or simulator behavior.

There are currently no automated tests in this directory.
